# Electric Vehicle Market Performance & Insights

## Project Overview
This project analyzes the electric vehicle (EV) market using Tableau Public. It explores sales trends, manufacturers, battery technologies, customer ratings, and battery performance.

## Tools Used
- Tableau Public
- Excel / CSV
- GitHub

## Dashboards
The project contains 8 visualizations across 2 dashboards:
1. Top 10 EV Manufacturers
2. Battery Technology Distribution
3. Annual EV Sales Trend
4. Average Customer Rating
5. Average Battery Capacity
6. Battery Degradation Analysis
7. Average Battery Cycle Life
8. Battery Degradation by Type

## Objective
To understand EV market performance and identify insights about sales, battery technology, and vehicle performance.
